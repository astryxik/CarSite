# RENTCARS

Лендинг сервиса аренды автомобилей — одностраничное приложение на React + Vite.

## Описание

Сайт знакомит пользователя с сервисом аренды машин: как он работает, почему стоит его выбрать, какие авто доступны, и предлагает скачать мобильное приложение. Реализованы интерактивные модальные окна для регистрации, входа, поиска авто, оформления аренды и отправки отзыва.

## Секции страницы

| Секция | Якорь | Содержимое |
| --- | --- | --- |
| **Nav** | — | Логотип, ссылки «Become a renter» / `#deals` / `#how` / `#why`, кнопки входа или приветствие с кнопкой «Log out» при активной сессии |
| **Hero** | — | Заголовок с акцентом «Easily», фото автомобиля, бейджи App Store / Google Play, форма поиска (локация, дата выдачи и возврата) |
| **How it works** | `#how` | 3 шага (выбор локации, даты, авто) + логотипы 6 партнёров |
| **Why choose us** | `#why` | Фото автомобиля и 4 преимущества: лучшая цена, опытные водители, доставка за 24 часа, поддержка 24/7 |
| **Deals** | `#deals` | Каталог из 4 авто (Jaguar XE, Audi R8, BMW M3, Lamborghini Huracan) с рейтингом, характеристиками и ценой; кнопки «Rent Now» и «Show all vehicles» |
| **Reviews** | `#reviews` | 3 отзыва с рейтингом 5.0 и кнопка «Leave a review» |
| **Download** | `#download` | Промо мобильного приложения, бейджи сторов, мокап телефона |
| **Footer** | — | Контакты, 3 колонки ссылок, соцсети (Facebook, Instagram, YouTube), копирайт |

## Модальные окна

| Окно | Хеш URL | Описание |
| --- | --- | --- |
| Вход | `#signin` | Валидация полей, проверка существования аккаунта и пароля |
| Регистрация | `#signup` | Проверка длины пароля (≥ 6), совпадения паролей, дубликата email |
| Поиск | `#search` | Локация и даты (по умолчанию 15–16.02.2026), список авто с кнопкой «Rent» |
| Аренда | `#rent` | Бронирование выбранного авто по датам, подтверждение через тост |
| Отзыв | `#review` | Имя, интерактивный рейтинг звёзд 1–5, текст отзыва |

Общее поведение модалок:

- открытие/закрытие синхронизируется с хешем URL (`history.replaceState`) — окно можно открыть сразу при загрузке (`/#rent`)
- закрытие по клавише `Esc`, по клику на оверлей и по кнопке ✕
- автофокус на первом поле ввода через 60 мс
- блокировка прокрутки фона (`body.is-locked`)
- доступность: `role="dialog"`, `aria-modal`, `aria-labelledby`, `aria-label` у кнопок

## Данные и хранение

Все операции с `localStorage` обёрнуты в try/catch (`src/data.js`):

| Ключ | Назначение |
| --- | --- |
| `rentcars_users` | Список зарегистрированных пользователей |
| `rentcars_session` | Текущая сессия (имя и email) |
| `rentcars_reviews` | Отправленные отзывы |

Тост-уведомления: единый блок внизу экрана (`role="status"`), автоскрытие через 3.2 с.

## Установка и запуск

```bash
# клонировать репозиторий
git clone <repo-url>
cd "car site"

# установить зависимости
npm install

# запустить dev-сервер
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`.

## Скрипты

## Адаптивность

4 брейкпоинта: `1250px`, `1024px`, `640px` (общие) и `640px` (модальные окна). Плавная прокрутка по якорям (`scroll-behavior: smooth`), переходы hover/focus без `@keyframes`.

## Ограничения

- Нет серверной части — все данные хранятся в `localStorage` браузера
- Меню на экранах ≤ 1024px скрывается (бургер-меню не реализовано), шапка не sticky
- Поиск и фильтрация авто условные: список всегда из 4 автомобилей из `src/data.js`
- Ссылки в футере и на сторы ведут на заглушку `#`
